# Anubis Application

An iOS application designed to assist with managing auction inventory in the field.

Featuring:
+ Offline functionality
+ Automatic and Manual Syncing (wip)
+ A robust lot creation system (wip)

## Building
1. In XCode, Clone repository from https://github.com/Nas-Tech/anubis-ios-app.git
2. Build and run

## Dependencies
No dependencies yet

## System requirements
iPhone running iOS 16.6 or newer
